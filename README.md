
# Tic-Tac-Toe

A Tic-Tac-Toe mobile application built with React Native, TypeScript, Expo, and Expo Router for DAUST Mobile Development.

## Features

- Interactive 3 × 3 game board
- Alternating X and O turns
- Winner and draw detection
- Prevention of overwriting played squares
- Move history and time travel
- Drawer navigation with Game, Settings, and About
- Shared light and dark themes
- Theme-aware header, drawer, board, move history, and status bar
- Application version displayed on the About screen

## Technologies

- React Native
- TypeScript
- Expo
- Expo Router
- React Context API
